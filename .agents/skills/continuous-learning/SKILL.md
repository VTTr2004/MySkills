# Continuous Learning

Use this skill to update the skill pack safely.

## Workflow

1. Read `skill-evolution/README.md` first.
2. Read only the relevant raw notes from `knowledge-from-workshop/`.
3. Classify each lesson as principle, heuristic, template, agent role, skill module, or example.
4. Ask before turning ambiguous lessons into hard rules.
5. Update the smallest useful surface: reference, template, subagent, skill module, or diagram.
6. Validate changed skills.
7. Summarize what changed and what remains open.

## Guardrails

- Do not paste raw workshop notes into core skills.
- Do not grow one giant skill file.
- Do not load enterprise process unless the project needs it.
- Keep future updates modular and discoverable.
