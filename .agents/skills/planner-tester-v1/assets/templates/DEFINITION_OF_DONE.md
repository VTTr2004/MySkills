# Definition Of Done

This project is done when:

- [ ] Approved `PROJECT_PLAN.md` exists
- [ ] Approved `REQUIREMENT_SUMMARY.md` exists
- [ ] Approved `EVALUATION_PLAN.md` exists
- [ ] Approved `TEST_CASES.md` exists
- [ ] Approved `DEFINITION_OF_DONE.md` exists
- [ ] Implementation, when later allowed, satisfies acceptance criteria
- [ ] Required tests or evals are run
- [ ] Evidence is recorded
- [ ] Known limitations are listed
- [ ] User or reviewer approval is complete when required
