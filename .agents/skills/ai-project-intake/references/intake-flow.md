# AI Intake Flow

Ask 1-3 questions at a time.

Question groups:
1. Project idea, target user, demo goal
2. AI agent job and expected outputs
3. Data, tools, RAG, APIs, database, or private documents
4. Sample inputs and expected behavior
5. Success criteria, failure modes, and evaluation metrics
6. Timebox, frontend/API/CLI needs, and constraints
7. Open addition check before summary

After each meaningful answer:
- Accept if clear and scope-fit.
- Ask a sharper follow-up if vague.
- Offer options if too broad or risky.
- Recommend a default, but let the user choose.
