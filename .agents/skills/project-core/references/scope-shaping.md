# Scope Shaping

Use a flexible scope profile instead of forcing one fixed level.

Dimensions:
- Delivery mode: spike, course demo, reusable prototype, demo day, work project, product
- AI complexity: none, low, medium, high
- Data complexity: none, static files, RAG, external API, database
- UI complexity: none, thin, demo-focused, product-like
- Backend complexity: none, thin wrapper, service, platform
- Evaluation rigor: light, standard, strong, research-grade
- Engineering maturity: throwaway, reusable, maintainable, deployable, governed
- Timebox fit: comfortable, tight, unrealistic

Output:
- Closest preset, if useful
- Where the preset does not fit
- Overbuild risks
- Underbuild risks
- Must include
- Should include
- Defer
- Explicit non-goals
- Questions for the user
