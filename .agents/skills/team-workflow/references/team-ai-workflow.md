# Team + AI Workflow

Big picture:
1. Brainstorm: need, goal, user, rough direction
2. Specs: domains, features, roles, API contracts, business rules
3. Architecture: ADRs, stack, folder structure, conventions
4. Planning: backlog, sprint, user stories, tasks, estimates
5. Parallel execution: people and agents work from shared context
6. Review and merge: PR/review, verify, resolve conflicts
7. Next sprint: retro, improve, repeat

Shared context base:
- Specs
- ADRs
- Contracts
- Rules and conventions
- Current tasks and status

Principle: correct context -> correct AI understanding -> correct code -> correct product.
