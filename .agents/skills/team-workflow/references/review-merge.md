# Review And Merge

Before merge or handoff, check:
- Requirements satisfied
- Contracts unchanged or documented
- Tests/evals run
- Docs updated
- Decision log updated when architecture changed
- Worklog or task status updated
- Known limitations recorded

For AI agents:
- Return findings with file references.
- Prioritize bugs, regressions, missing tests, contract drift, and security risks.
- Do not bury serious issues under summary text.
