# Evaluation Strategy

Choose checks based on risk:
- Spike: sample inputs and observed outputs
- Demo: 5+ acceptance or AI eval cases
- Reusable prototype: 10+ eval cases plus basic automated tests
- Team/work project: unit/integration/e2e or AI eval evidence tied to tasks
- Product: release gates, monitoring, rollback, security checks as needed

For each check, record:
- Input or scenario
- Expected behavior
- How to measure
- Result
- Evidence
