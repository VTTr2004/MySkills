# Definition Of Done

A task is done only when it meets its agreed standard.

Default DoD:
- Code implemented
- Tests or eval cases run
- No known lint/type errors for touched area
- Docs or contracts updated when behavior changed
- Decision log updated when architecture changed
- Task status updated
- Known limitations recorded
- Reviewer or user approval obtained when required

Adjust DoD to project maturity. Do not force product-grade DoD on a spike.
