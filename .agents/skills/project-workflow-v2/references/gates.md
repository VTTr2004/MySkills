# Gates

## Gate 1: Product Planning Approval

Required:

- `PROJECT_PLAN.md`
- `REQUIREMENT_SUMMARY.md`
- explicit user approval

## Gate 2: Testing Approval

Required:

- `EVALUATION_PLAN.md`
- `TEST_CASES.md`
- `DEFINITION_OF_DONE.md`
- explicit user approval

## Gate 3: Technical Approval

Required:

- `TECHNICAL_DESIGN.md`
- `IMPLEMENTATION_PLAN.md`
- technical review completed
- explicit user approval

Optional but required when relevant:

- `FOLDER_STRUCTURE.md`
- `INTERFACE_CONTRACTS.md`
- `LOGGING_PLAN.md`
- `RUNBOOK.md`

## Final Handoff

Required:

- changed files summary
- checks run
- eval/test evidence
- known limitations
- remaining risks or next steps
