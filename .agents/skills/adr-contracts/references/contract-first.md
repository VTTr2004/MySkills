# Contract First

Use contracts to let teams and agents work in parallel without implicit dependencies.

Contract types:
- REST endpoint contract
- Python function or module interface
- Event schema
- Data model schema
- Agent input/output contract
- UI/API boundary

Each contract should define:
- Purpose
- Inputs
- Outputs
- Error cases
- Examples
- Version or change notes
- Owner

When a contract changes, review dependent tasks before coding further.
