# ADR Guidance

Create ADRs for decisions that affect multiple files, agents, teams, or future maintenance.

Good ADR topics:
- Test strategy
- Domain split
- API contract first
- Project structure and coding conventions
- Tech stack
- Data storage or RAG approach
- Deployment approach

ADR format:
- Title
- Status
- Context
- Decision
- Options considered
- Consequences
- Review date, if temporary

Do not create ADRs for trivial implementation details.
