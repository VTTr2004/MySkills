# Module Map

## Skill Modules

`project-core`
: Base workflow for all projects: clarify goal, shape scope, maintain context, plan, and hand off.

`ai-project-intake`
: AI-specific intake: agent job, data/tools/RAG, evaluation, demo behavior.

`team-workflow`
: Team + AI workflow: specs, planning, tasks, sprint loop, review, merge.

`enterprise-project`
: Work-grade governance: traceability, risk, ownership, security, release discipline.

`adr-contracts`
: Architecture decisions, domain boundaries, API/event contracts, conventions.

`eval-and-dod`
: Evaluation cases, acceptance criteria, Definition of Done, evidence.

`continuous-learning`
: Convert workshop notes and project retrospectives into safe skill updates.

## Legacy Skill

`vinuni-ai-project`
: Existing portable skill pack. Keep it usable. It can reference the modular skills but should not absorb all details.

## Raw Knowledge

`knowledge-from-workshop/`
: Raw notes. Read when updating, but do not treat every note as an official rule.

`skill-evolution/`
: Update hub. Read first before evolving the system.
