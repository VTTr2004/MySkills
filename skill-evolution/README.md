# Skill Evolution Hub

Read this folder first when improving this skill pack.

Purpose:
- Keep future upgrades modular instead of growing one huge skill file.
- Convert workshop notes into reviewed principles, references, templates, agents, or skills.
- Preserve the user's working style: plan first, context first, contract first, eval first, then code.

Suggested read order for future updates:
1. `upgrade-protocol.md`
2. `design-principles.md`
3. `module-map.md`
4. `subagent-strategy.md`
5. `upgrade-backlog.md`

Raw learning notes stay in `knowledge-from-workshop/`.
Curated implementation rules belong in `.agents/skills/*/references/` or `vinuni-ai-project/references/`.
