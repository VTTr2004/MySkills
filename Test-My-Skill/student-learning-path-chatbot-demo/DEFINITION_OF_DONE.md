# Definition Of Done

This project is done when:

- [ ] Approved `PROJECT_PLAN.md` exists
- [ ] Approved `REQUIREMENT_SUMMARY.md` exists
- [ ] Approved `EVALUATION_PLAN.md` exists
- [ ] Approved `TEST_CASES.md` exists
- [ ] Approved `DEFINITION_OF_DONE.md` exists
- [ ] Demo scope remains limited to a student-facing chatbot for personalized learning paths
- [ ] A small sample course-content dataset exists for at least two subjects
- [ ] The chatbot asks clarifying questions before detailed planning when subject, goal, level, or time budget is missing
- [ ] The chatbot can produce an ordered learning path after receiving enough student context
- [ ] Learning-path recommendations are grounded in available course content
- [ ] The chatbot keeps workload realistic for the stated time budget
- [ ] The chatbot keeps subject content separated
- [ ] The chatbot states limitations when course content is missing
- [ ] The chatbot does not promise grade improvement, invent official course content, or give advice outside the learning-support scope
- [ ] All high-priority test cases in `TEST_CASES.md` pass
- [ ] At least 80% of medium-priority test cases in `TEST_CASES.md` pass
- [ ] Evidence is recorded as short transcripts or screenshots for each evaluation case
- [ ] Known limitations are listed before any demo handoff
- [ ] User or reviewer approves Phase 2 artifacts before any later implementation phase starts

Implementation remains blocked in planner-tester-v1 until the user explicitly starts a later Coder phase.
