# Definition Of Done

This work is done when:

- [ ] Approved scope is implemented
- [ ] Acceptance criteria are satisfied
- [ ] Required tests or eval cases are run
- [ ] Evidence is recorded
- [ ] Docs, specs, ADRs, or contracts are updated if behavior changed
- [ ] Worklog and decision log are updated
- [ ] Known limitations are documented
- [ ] User or reviewer approval is complete if required
