# AGENTS.md - VinUni AI Project Workflow

Before coding, run the VinUni AI Project intake workflow.

Use the skill pack at:

```text
K:\AI_IN_ACTION\vinuni-ai-project-skill\vinuni-ai-project
```

Rules:

1. Ask intake questions before implementation.
2. Shape scope using presets only as guidance; do not force Level 0-4 as a rigid classifier.
3. Create the smallest useful artifact set: project brief, architecture, evaluation plan, implementation plan, and context summary when useful.
4. For larger/team/work projects, add specs, ADRs, contracts, DoD, review, and handoff artifacts only when needed.
5. Ask for approval before scaffolding.
6. Keep backend/frontend thin unless the confirmed scope requires more.
7. Update `WORKLOG.md`, `DECISION_LOG.md`, and `CONTEXT_SUMMARY.md` when present.
8. Treat the AI agent, evaluation, logs, and future handoff as the core of the project.
